# 맛다톤 2026: 2030 생활 밀착형 아이디어 5선

## 1. 방향

이 문서는 `docs/SCORING.md`를 기준으로 **20~30대가 일상에서 자주 겪는 문제**를 해결하면서 91점 이상을 목표로 할 수 있는 아이디어 5개를 제안한다.

개발자 전용 도구는 제외하고 다음 생활 영역에 집중했다.

- 놓치기 쉬운 생활 행정과 기한
- 처음이라 어려운 자취와 주거 계약
- 반복 지출과 구독 관리
- 취업·이직 준비의 정보 비대칭
- 중고거래와 온라인 사기 위험

> 목표 점수는 아이디어만으로 받는 점수가 아니다. 제안된 기능, Copilot SDK 및 Agent Framework 사용, Azure 연결, 테스트, Before/After 측정이 실제 제출물에서 확인될 때의 목표치다.

## 2. 90점 초과 공통 조건

- Copilot SDK를 문맥 유지, 후속 질문, 도구 호출, 사용자 수정에 실제 사용한다.
- Agent Framework로 최소 3개 에이전트의 역할, 상태, 분기, 재시도를 구현한다.
- Azure를 단순 배포처가 아니라 문서 처리, 검색, 저장, 알림 중 핵심 기능에 연결한다.
- 로그인 없는 샘플 모드에서 `입력 → 분석 → 근거 확인 → 사용자 선택 → 결과 내보내기`를 3분 안에 완주한다.
- 같은 샘플을 사람이 처리했을 때와 비교해 시간, 단계, 누락, 오류 감소를 수치로 보여준다.
- 사용자의 소비, 계약, 개인정보를 학습 데이터로 사용하지 않으며 필요한 데이터만 최소한으로 저장한다.
- AI가 법률·금융·채용 결과를 확정하지 않고 출처, 불확실성, 사용자 승인 단계를 제공한다.
- 모델 타임아웃, Azure 오류, 잘못된 파일, 근거 부족을 정상적인 실패 상태로 처리한다.

### 1위. 생활 마감 매니저 `LifeAdmin` — 94점

#### 한 줄 가치

고지서, 안내문, 이메일을 넣으면 **내가 해야 할 일, 준비물, 금액, 기한을 근거와 함께 정리하고 실행 일정으로 바꿔준다.**

#### 대상 사용자

독립 생활을 시작한 사회초년생, 자취생, 맞벌이 가구처럼 공과금, 보험, 갱신, 행정 안내를 여러 채널에서 받는 20~30대.

#### 해결할 문제

생활 문서는 길고 표현 방식이 달라 중요한 기한을 놓치기 쉽다. 사용자는 문서를 읽은 뒤에도 무엇을 언제까지 해야 하는지 직접 달력과 할 일 앱에 다시 입력한다.

#### 3분 데모 흐름

1. 통신비 고지서, 건강검진 안내, 임대차 갱신 안내 샘플을 불러온다.
2. 문서 정리 에이전트가 날짜, 금액, 기관, 준비물을 구조화한다.
3. 행동 추출 에이전트가 `납부`, `예약`, `제출`, `갱신` 작업을 만든다.
4. 검증 에이전트가 각 작업을 원문 문장과 대조하고 불명확한 내용은 질문한다.
5. 사용자가 작업을 승인하거나 기한과 알림 시점을 수정한다.
6. 승인된 작업만 주간 보드와 캘린더 파일로 내보낸다.
7. 수작업 대비 정리 시간과 누락 항목 수를 보여준다.

#### 에이전트와 도구

- 문서 정리 에이전트: 서로 다른 문서에서 핵심 필드를 추출한다.
- 행동 추출 에이전트: 정보를 실행 가능한 작업과 선행 조건으로 바꾼다.
- 검증 에이전트: 원문 근거와 추출 결과를 대조하고 근거 없는 작업을 차단한다.
- 일정 에이전트: 중복 기한을 합치고 승인된 작업만 일정으로 만든다.
- Copilot SDK: 문서 검색, 후속 질문, 작업 수정, 캘린더 내보내기 도구를 호출한다.
- Agent Framework: 병렬 문서 분석, 근거 검증, 승인, 내보내기의 상태를 관리한다.

#### Azure 핵심 연동

- Azure AI Document Intelligence: 고지서와 안내문의 표, 날짜, 금액 추출
- Azure AI Search: 작업과 원문 페이지·문장 연결
- Azure Cosmos DB: 사용자 승인 상태와 수정 이력 저장
- Azure Functions: 캘린더 파일 생성과 선택적 알림 예약
- Application Insights: 단계별 처리 시간, 실패, 재시도 기록

### 2위. 첫 자취 주거 코파일럿 `HomeMate` — 93점

#### 한 줄 가치

전월세 계약서와 집 상태를 확인해 **놓치기 쉬운 조항, 입주 전 질문, 방별 점검 목록을 근거와 함께 준비해준다.**

#### 대상 사용자

첫 독립이나 이사를 준비하지만 계약 용어, 특약, 입주 점검 경험이 부족한 20~30대 세입자.

#### 해결할 문제

계약서에는 어려운 용어가 많고, 집을 보는 짧은 시간에 수압, 곰팡이, 옵션 상태, 관리비 항목을 모두 확인하기 어렵다. 인터넷 체크리스트는 내 계약과 집 조건을 반영하지 못한다.

#### 3분 데모 흐름

1. 합성 임대차 계약서와 집 정보 샘플을 불러온다.
2. 계약 해석 에이전트가 보증금, 기간, 관리비, 수리 책임, 특약을 구조화한다.
3. 위험 확인 에이전트가 누락·모호·추가 질문이 필요한 조항을 분류한다.
4. 입주 점검 에이전트가 집 조건에 맞는 현장 체크리스트를 만든다.
5. 검증 에이전트가 모든 설명에 계약서 페이지와 공공 가이드 출처를 연결한다.
6. 사용자가 확인 결과와 사진 메모를 추가하고 인수인계 PDF를 내보낸다.

#### 에이전트와 도구

- 계약 해석 에이전트: 계약 필드와 특약을 구조화한다.
- 위험 확인 에이전트: 법적 결론 대신 확인 필요 항목과 질문을 만든다.
- 현장 점검 에이전트: 원룸, 오피스텔 등 주거 형태에 맞춰 순서를 조정한다.
- 근거 검증 에이전트: 계약 원문과 신뢰할 수 있는 공공 가이드만 인용한다.
- Copilot SDK: 조항 찾기, 질문 수정, 사진 메모, PDF 내보내기 도구를 호출한다.
- Agent Framework: 계약 검토와 현장 점검을 병렬 수행한 뒤 최종 계획으로 합친다.

#### Azure 핵심 연동

- Azure AI Document Intelligence: 계약서 구조와 특약 추출
- Azure AI Search: 계약 원문과 사전에 준비한 공공 주거 가이드 검색
- Blob Storage: 만료 정책이 적용된 합성 계약서와 점검 사진 저장
- Cosmos DB: 항목별 확인·보류·완료 상태 저장
- Azure Functions: 점검 결과 PDF 생성

### 3위. 반복 지출 리셋 코치 `WalletReset` — 93점

#### 한 줄 가치

카드 사용 내역을 넣으면 **구독, 반복 지출, 가격 인상, 사용하지 않는 결제를 찾아 사용자가 선택할 절약 계획으로 바꿔준다.**

#### 대상 사용자

여러 구독과 간편결제를 사용하면서 어디에서 돈이 새는지 파악하기 어려운 사회초년생과 1인 가구.

#### 해결할 문제

소액 결제는 여러 상호명으로 표시되고 결제일도 달라 한 달 지출에서 찾기 어렵다. 가계부는 분류 결과를 보여주지만 어떤 행동부터 해야 하는지 결정하려면 다시 검토해야 한다.

#### 3분 데모 흐름

1. 개인정보를 제거한 합성 카드 CSV를 불러온다.
2. 거래 정리 에이전트가 상호명을 정규화하고 지출 범주를 제안한다.
3. 반복 패턴 에이전트가 구독, 중복 서비스, 가격 인상 후보를 탐지한다.
4. 검증 에이전트가 금액과 날짜를 다시 계산하고 확실하지 않은 항목을 질문한다.
5. 계획 에이전트가 `유지`, `검토`, `중단 후보`로 나누고 월 절감액을 계산한다.
6. 사용자가 항목을 직접 확정하면 30일 절약 계획과 CSV를 내보낸다.

#### 에이전트와 도구

- 거래 정리 에이전트: 상호명과 카테고리를 정규화한다.
- 반복 패턴 에이전트: 규칙 기반 계산과 AI 설명을 결합한다.
- 검증 에이전트: 합계와 절감액을 결정적 코드로 재계산한다.
- 행동 계획 에이전트: 사용자가 선택한 항목만 우선순위 계획으로 만든다.
- Copilot SDK: 거래 필터, 항목 수정, 재계산, CSV 내보내기 도구를 호출한다.
- Agent Framework: 탐지, 검증, 사용자 확정, 계획 생성 상태를 관리한다.

#### Azure 핵심 연동

- Azure Functions: CSV 검증, 반복 결제 탐지, 절감액 결정적 계산
- Cosmos DB: 가명화된 세션과 사용자 분류 수정 저장
- Blob Storage: 짧은 만료 정책이 적용된 원본·결과 파일 저장
- Azure AI Search: 상호명 별칭과 서비스 범주 검색
- Application Insights: 계산 오류와 에이전트 실패 추적

### 4위. 취업 준비 내비게이터 `CareerCompass` — 92점

#### 한 줄 가치

관심 채용 공고와 내 경험을 비교해 **근거 있는 강점, 부족한 증거, 이번 주 준비 행동을 만들어준다.**

#### 대상 사용자

첫 취업, 직무 전환, 이직을 준비하지만 공고마다 요구사항이 달라 무엇부터 준비해야 할지 막막한 20~30대.

#### 해결할 문제

지원자는 채용 공고의 필수·우대 조건을 직접 분해하고 자신의 경험과 연결한다. 일반적인 자기소개서 생성기는 그럴듯한 문장을 만들지만 실제 경험이 없는 내용을 섞을 위험이 있다.

#### 3분 데모 흐름

1. 샘플 채용 공고와 합성 경험 카드 8개를 불러온다.
2. 공고 분석 에이전트가 필수 조건, 우대 조건, 업무를 구조화한다.
3. 경험 매칭 에이전트가 각 조건에 사용자의 실제 경험 근거를 연결한다.
4. 정직성 검증 에이전트가 근거 없는 주장과 과장 표현을 차단한다.
5. 계획 에이전트가 `지원 가능`, `보완 필요`, `질문 준비`와 7일 행동 계획을 만든다.
6. 사용자가 결과를 수정하고 면접 준비 카드로 내보낸다.

#### 에이전트와 도구

- 공고 분석 에이전트: 요구 역량과 업무를 구분한다.
- 경험 매칭 에이전트: 경험 카드만 근거로 강점을 연결한다.
- 정직성 검증 에이전트: 새로운 경력·수치 창작을 차단한다.
- 준비 계획 에이전트: 부족한 증거를 작은 행동으로 바꾼다.
- Copilot SDK: 공고 검색, 경험 선택, 근거 열기, 계획 내보내기 도구를 호출한다.
- Agent Framework: 병렬 매칭, 반론 검증, 사용자 승인 흐름을 관리한다.

#### Azure 핵심 연동

- Azure AI Document Intelligence: PDF 공고와 이력서 구조 추출
- Azure AI Search: 공고 조건과 경험 카드의 근거 검색
- Cosmos DB: 사용자가 승인한 경험 연결과 준비 상태 저장
- Azure Functions: 주간 계획과 면접 카드 PDF 생성
- Azure AI Content Safety: 공격적이거나 차별적인 생성 내용 보조 점검

#### 목표 점수와 증거

| 영역 | 목표 | 제출물에서 확인할 증거 |
| --- | ---: | --- |
| A1 | 24/25 | 병렬 매칭, 정직성 검증, 사용자 수정, 내보내기 도구 호출 |

합격 가능성 점수, 자동 지원, 채용 차별 판단은 제공하지 않는다. 공고 두 종류와 합성 경험 카드만 사용하며 사용자가 입력하지 않은 경력은 생성하지 않는다.

### 5위. 중고거래 안전 동행 `SafeDeal` — 91점

#### 한 줄 가치

중고거래 글과 대화를 넣으면 **위험 신호, 추가 확인 질문, 안전한 거래 순서를 근거와 함께 알려준다.**

#### 대상 사용자

중고거래, 티켓 양도, 공동 구매를 자주 이용하지만 사기 수법과 안전 확인 절차를 모두 알기 어려운 20~30대.

#### 해결할 문제

급하게 구매할 때 외부 메신저 유도, 시세보다 낮은 가격, 선입금 재촉 같은 신호를 놓치기 쉽다. 단일 키워드 경고는 정상 거래도 사기로 오인하며 무엇을 확인해야 하는지 알려주지 않는다.

#### 3분 데모 흐름

1. 합성 판매 글, 대화, 상품 정보를 불러온다.
2. 신호 탐지 에이전트가 가격, 결제 요구, 연락 방식의 위험 후보를 찾는다.
3. 맥락 검증 에이전트가 각 신호의 대화 근거와 반대 근거를 함께 확인한다.
4. 확인 계획 에이전트가 판매자에게 물을 질문과 안전한 거래 순서를 만든다.
5. 사용자가 새 답변을 추가하면 위험 상태와 체크리스트가 갱신된다.
6. 최종 결과를 `낮음`, `주의`, `중단 권고`로 표시하고 증거 리포트를 내보낸다.

#### 에이전트와 도구

- 거래 정리 에이전트: 글, 대화, 가격 정보를 구조화한다.
- 위험 신호 에이전트: 규칙 기반 신호와 AI 맥락 분석을 결합한다.
- 반론 검증 에이전트: 정상일 가능성과 근거 부족을 함께 표시한다.
- 확인 계획 에이전트: 사용자가 직접 수행할 질문과 행동을 만든다.
- Copilot SDK: 시세 샘플 검색, 근거 열기, 답변 추가, 리포트 내보내기를 호출한다.
- Agent Framework: 탐지 → 반론 → 사용자 확인 → 재평가 상태를 관리한다.

#### Azure 핵심 연동

- Azure AI Search: 사전에 준비한 공공 사기 예방 가이드와 시세 샘플 검색
- Azure AI Content Safety: 대화의 위협·유해 표현 보조 탐지
- Cosmos DB: 가명화된 검토 상태와 사용자 확인 결과 저장
- Azure Functions: 규칙 기반 위험 신호와 최종 체크리스트 계산
- Application Insights: 오탐 수정, 도구 오류, 처리 시간 추적

#### 목표 점수와 증거

| 영역 | 목표 | 제출물에서 확인할 증거 |
| --- | ---: | --- |
| A1 | 23/25 | 탐지·반론 에이전트와 새 답변에 따른 상태 재평가 |
| A2 | 17/18 | 위험 신호 확인 시간과 놓친 신호 수 전후 비교 |
| A3 | 17/18 | Search 가이드 출처, Content Safety 결과, Functions 신호 |
| A4 | 14/16 | 정상·주의·위험 합성 사례 3개의 E2E 테스트 |
| A5 | 11/12 | 위험 이유, 반대 근거, 다음 행동을 한 화면에 표시 |
| A6 | 6/6 | 사기 확정 금지, 개인정보 마스킹, 근거 부족 상태, 신고 안내 |
| A7 | 3/5 | 단순 위험 점수보다 대화형 확인과 반론 검증에 집중 |

#### 안전장치와 범위

실명, 계좌번호, 전화번호는 저장 전에 마스킹한다. 특정 사용자를 범죄자로 단정하지 않고 `위험 신호가 있음`으로 표현하며, 실제 계좌 조회나 자동 신고는 제외한다.

## 5. 최종 추천

### 최우선 추천: `LifeAdmin`

`LifeAdmin`은 20~30대뿐 아니라 누구나 겪는 생활 문서 문제를 다루므로 가장 범용적이다.

- 고지서, 안내문, 갱신 문서처럼 문제와 입력이 직관적이다.
- 결과가 요약이 아니라 할 일과 기한으로 바뀌어 생산성 효과가 명확하다.
- 세 가지 합성 문서만으로도 로그인 없는 3분 데모를 완주할 수 있다.
- Document Intelligence, AI Search, Cosmos DB, Functions가 각각 분명한 역할을 가진다.
- 원문 근거, 승인, 민감정보 마스킹이 UX와 책임 있는 AI 점수에 동시에 기여한다.

### 공감도 우선 추천: `HomeMate`

첫 자취와 이사는 20~30대가 강하게 공감하는 주제다. 모바일로 집을 보면서 체크하고 계약 조항과 현장 사진을 연결하는 장면이 시각적으로 좋아 발표 임팩트도 크다.

### 수치 증명 우선 추천: `WalletReset`

반복 지출 탐지 시간과 월 절감 후보 금액을 바로 숫자로 보여줄 수 있어 A2 점수를 입증하기 쉽다. 다만 금융 조언으로 보이지 않도록 자동 해지나 투자 추천은 반드시 제외한다.

## 6. 고득점 최소 제출 증거

1. 로그인 없는 샘플 데모 URL
2. 입력부터 내보내기까지 끊기지 않는 3분 사용자 시나리오
3. Copilot SDK 도구 호출 로그와 Agent Framework 실행 타임라인
4. 앱에서 확인되는 실제 Azure 리소스 응답과 저장 ID
5. 동일 샘플의 수작업 대비 시간·단계·누락 Before/After 표
6. 정상 흐름, 빈 입력, 모델 타임아웃, Azure 오류 테스트
7. AI 근거, 불확실성, 사용자 승인·거부·수정 화면
8. 합성 데이터, 최소 수집, 삭제, 비밀 정보 관리 설명
9. 핵심 API 단위 테스트와 전체 사용자 흐름 E2E 결과
10. 실행 방법, 아키텍처, 한계가 포함된 README

이 증거가 실제 저장소와 데모에 없으면 설명만 있는 것으로 판단되어 목표 점수를 받기 어렵다.
