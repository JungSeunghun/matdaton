# 해커톤 AI 심사 점수 규정

## 1. 기본 원칙

- 총점은 100점이며, AGENT1부터 AGENT7까지 각 담당 영역을 독립적으로 평가한다.
- 모든 점수는 제출물, 실행 가능한 데모, 소스 코드, 구성 파일, 배포 결과, 발표 자료에서 확인되는 증거를 근거로 부여한다.
- 설명만 있고 구현 또는 검증 가능한 증거가 없으면 해당 항목은 최대 배점의 40%를 초과할 수 없다.
- 저장소나 데모에서 확인할 수 없는 기능은 구현된 것으로 추정하지 않는다.
- 각 에이전트는 근거, 감점 사유, 개선 제안을 함께 출력한다.
- 최종 점수는 각 에이전트 점수의 단순 합계로 계산하며 소수점 둘째 자리에서 반올림한다.

## 2. 공통 채점 척도

각 세부 항목은 아래 달성률을 기준으로 점수를 계산한다.

| 등급 | 달성률 | 판단 기준 |
| --- | ---: | --- |
| 탁월 | 90~100% | 요구를 완전히 충족하고, 실제 사용 가능한 수준으로 검증되었으며 완성도가 높다. |
| 우수 | 75~89% | 핵심 요구를 충족하고 정상 동작하지만 일부 개선 여지가 있다. |
| 보통 | 50~74% | 기본 구현은 확인되지만 범위, 품질, 검증 중 하나 이상이 부족하다. |
| 미흡 | 25~49% | 부분 구현 또는 개념 증명 수준이며 핵심 결함이 있다. |
| 매우 미흡 | 1~24% | 관련 시도는 있으나 실질적인 구현이나 효과를 확인하기 어렵다. |
| 미구현 | 0% | 구현 또는 확인 가능한 증거가 없다. |

세부 항목 점수는 `세부 배점 × 달성률`로 계산한다.

## 3. 에이전트별 평가 기준

### AGENT1: Copilot SDK 및 Agent Framework 활용 — 25점

| 세부 항목 | 배점 | 평가 기준 |
| --- | ---: | --- |
| Copilot SDK 활용 | 12.5점 | SDK가 핵심 기능에 실제로 사용되며, 단순 호출을 넘어 컨텍스트·도구·상호작용을 적절히 구성했는가 |
| Agent Framework 활용 | 12.5점 | 에이전트, 도구 호출, 오케스트레이션, 상태 또는 대화 흐름을 프레임워크로 적절히 구현했는가 |

단순 패키지 설치, 사용하지 않는 import, 화면상의 언급만으로는 활용 증거로 인정하지 않는다.

### AGENT2: 생산성 향상 및 문제 적합성 — 18점

| 세부 항목 | 배점 | 평가 기준 |
| --- | ---: | --- |
| 생산성 향상 | 9점 | 기존 작업 대비 시간, 단계, 반복 업무 또는 오류를 실질적으로 줄이는가 |
| 문제 적합성 | 9점 | 정의한 사용자와 문제를 정확히 겨냥하며, 핵심 기능이 문제 해결에 직접 기여하는가 |

생산성 효과를 전후 비교, 측정값, 사용자 시나리오로 입증한 경우 높은 점수를 부여한다.

## 4. AI 심사 출력 형식

각 에이전트는 다음 JSON 형식으로 결과를 반환한다.

```json
{
	"agent": "AGENT1",
	"score": 0,
	"maxScore": 25,
	"criteria": [
		{
			"name": "Copilot SDK 활용",
			"score": 0,
			"maxScore": 12.5,
			"evidence": ["확인한 파일, 실행 결과 또는 데모 장면"],
			"reason": "점수 산정 근거"
		}
	],
	"deductions": ["감점 사유"],
	"suggestions": ["개선 제안"],
	"confidence": "high | medium | low"
}
```

- `score`는 0 이상 `maxScore` 이하의 숫자여야 한다.
- `score`는 `criteria`에 포함된 세부 점수의 합과 같아야 한다.
- `evidence`에는 확인 가능한 경로, 실행 결과, 배포 리소스 또는 데모 구간을 구체적으로 기록한다.
- 증거가 불충분하면 `confidence`를 낮추고 추정으로 점수를 올리지 않는다.

## 5. 최종 집계 및 동점 처리

최종 점수는 다음과 같이 계산한다.

`최종 점수 = AGENT1 + AGENT2 + AGENT3 + AGENT4 + AGENT5 + AGENT6 + AGENT7`

동점인 경우 아래 순서로 높은 점수를 받은 팀을 우선한다.

1. AGENT1: Copilot SDK 및 Agent Framework 활용
2. AGENT2: 생산성 향상 및 문제 적합성
3. AGENT4: 기능 완성도 및 기술 구현
4. AGENT3: Azure 클라우드 연동
5. AGENT5: 사용자 경험 및 워크플로 설계
6. AGENT6: 책임 있는 AI, 보안 및 신뢰성
7. AGENT7: 혁신성 및 독창성

모든 에이전트 점수까지 같으면 공동 순위로 처리한다.
